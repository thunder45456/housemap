# HouseMap: แมพมีข้อมูลอะไร และใช้ทำอะไรได้บ้าง

ข้อมูลสถานที่ทั้งหมดมาจาก OpenStreetMap (OSM) ดึงเก็บเป็นไฟล์ในเว็บ ไม่ได้ดึงสดทุกครั้ง
ระยะทางที่ขึ้นในรายการเป็น **ระยะถนนจริง** (ไม่ใช่เส้นตรง) คิดจากบริการ OSRM

## 2. ใช้งานแมพได้อย่างไรบ้าง

### เพิ่มรายการ
- **ปักหมุด:** คลิกบนแผนที่ ลากหมุดปรับได้
- **วางพิกัด:** ช่อง "วางพิกัด" ใส่ `18.7961, 98.968` ระบบวางหมุดให้
- **วางลิงก์ Google Maps:** ลิงก์ยาว (ที่ขึ้นต้น google.com/maps...) ดึงพิกัดให้อัตโนมัติ
  - ลิงก์สั้น `maps.app.goo.gl/...` ไม่มีพิกัดในตัวลิงก์ ให้เปิดในเบราว์เซอร์ก่อนแล้วคัดลอกลิงก์ยาวจากแถบที่อยู่
  - หรือกดค้างที่หมุดใน Google Maps แล้วคัดลอกตัวเลขพิกัดมาวาง
- **ที่ดิน/บ้าน:** เลือกประเภท ถ้าเป็นที่ดินจะซ่อนห้องนอน/ห้องน้ำ/ชั้น/โรงรถ/พื้นที่ใช้สอย
- **ราคา:** เลือก "ราคารวม" หรือ "ราคาต่อพื้นที่" (บาท/ตร.วา, บาท/ตร.ม., บาท/ไร่) ใส่ขนาดไว้แล้วระบบคิดราคารวมให้ และรายละเอียดจะแสดงทั้งราคารวมและต่อพื้นที่เสมอ
- **ชื่อ:** ไม่ใส่ก็ได้ ระบบตั้งให้ เช่น `บ้าน 2.39M 70ตร.ม.` หรือ `ที่ดิน 3.5M 100ตร.วา`
- **AI prompt:** คัดลอก prompt ไปให้ AI อ่านประกาศ แล้ววางผลกลับมา

### ดูข้อมูลของแต่ละแปลง
คลิกแถวในรายการเพื่อขยาย จะเห็น
1. ราคารวม + ราคาต่อพื้นที่
2. ขนาดที่ดิน / พื้นที่ใช้สอย / ห้อง
3. ระยะถนนถึง รพ. ห้าง สนามบิน ตลาด ที่ใกล้สุด (ปุ่มไอคอนเส้นทางข้างแถว = วาดเส้นทางบนแผนที่)
4. สถานที่ที่คุณเลือกเอง (ห้าง/โรงเรียน ฯลฯ) ถ้ามี
5. โซนพื้นที่ (ประมาณ)

### เลือกเส้นทางเอง (ปุ่ม "เลือกสถานที่")
1. ขยายแปลง กดปุ่ม **เลือกสถานที่**
2. เลือกหมวด: ห้างสำคัญ / โรงเรียน / โรงพยาบาล / ตลาด / สนามบิน
3. เลือกรัศมี 5 / 10 / 15 / 20 ก.ม. (ตั้งต้น 10) พิมพ์ค้นหาชื่อได้ จุดทั้งหมดในรัศมีขึ้นเป็นจุดสีบนแผนที่
4. **ติ๊ก** สถานที่ที่สนใจ ระบบวาดเส้นทางและบอกระยะถนน/เวลาขับทันที
5. กด **บันทึกที่เลือก** เพื่อเก็บไว้กับแปลง (สูงสุด 8 แห่งต่อแปลง) เพื่อนที่เปิดมาจะเห็นเหมือนกัน
- ถ้าย้ายหมุดไปที่ใหม่ สถานที่ที่เลือกไว้จะถูกล้าง (เพราะคิดระยะจากจุดเดิม)

### ค้นหาและกรอง
- ตัวกรอง: ประเภท, ช่วงราคา, "ใกล้ รพ./ห้าง/สนามบิน/ตลาด ไม่เกิน X ก.ม.", โซน
- เรียง: ใหม่สุด, ราคา, ขนาดที่ดิน, พื้นที่ใช้สอย
- ชั้นแผนที่ (มุมขวาบนของแผนที่): เปิดหมุด รพ./ห้าง/สนามบิน/ตลาด และโซนสีบนแผนที่

### อื่น ๆ
- **ลบ** = ย้ายไป Bin กู้คืนได้
- **Export / Import JSON** สำรองและนำเข้าข้อมูล (นำเข้าแบบเพิ่ม ไม่ทับของเดิม)
- ถ้ามีคนแก้รายการเดียวกันพร้อมกัน ระบบเตือนและไม่ทับข้อมูลของเขา

## 3. คำถามที่พบบ่อย

- **รู้จักห้างทั้งหมดไหม?** ไม่ครบ: คัดเฉพาะห้างใหญ่และไฮเปอร์ 65 แห่งในภาคเหนือตอนบน
- **คิดระยะถึงถนนใหญ่ได้ไหม?** ทำได้ในทางเทคนิค (ใช้ถนนสายหลักจาก OSM) แต่ **ยังไม่ได้ทำ** ในรอบนี้
- **ระยะทางแม่นแค่ไหน?** เป็นระยะขับรถตามถนนที่ OSM รู้จัก ถ้าถนนใหม่ยังไม่อยู่ใน OSM ตัวเลขอาจเกินจริง
- **ข้อมูลอัปเดตเมื่อไร?** สถานที่ดึงเมื่อ 2026-11-10 (ห้างคัดใหม่ 2026-11-14) ถ้าอยากรีเฟรชต้องรันสคริปต์ใน `tools/`
