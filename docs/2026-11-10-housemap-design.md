# HouseMap — เว็บบันทึกบ้าน/ที่ดินที่น่าสนใจบนแผนที่ (Design)

วันที่: 2026-11-10 · ผู้ใช้: วิศวกรโครงสร้างชาวไทย ใช้ภาษาไทยเป็นหลัก ไม่ใช่นักพัฒนาเว็บ

## เจตนา (Why)
ผู้ใช้เปิดเว็บประกาศขายบ้านแล้วพบว่าไม่มีแผนที่ ทำให้ไม่เห็นทำเลและเปรียบเทียบหลายเว็บไม่ได้
ต้องการที่เดียวที่รวมบ้าน/ที่ดินที่น่าสนใจจากหลายเว็บ แสดงบนแผนที่ และใช้ร่วมกับเพื่อนในกลุ่มได้
(เพื่อนเพิ่มบ้านแล้วทุกคนเห็นตรงกัน)

## ขอบเขตพื้นที่
เชียงใหม่และจังหวัดข้างเคียง (ลำพูน ลำปาง เชียงราย แม่ฮ่องสอน ฯลฯ) แผนที่เริ่มที่เชียงใหม่ แต่ไม่ล็อกพื้นที่ในโค้ด

## Goals (ขั้นที่ 1 — ทำก่อน)
1. แผนที่ แสดงบ้าน/ที่ดินเป็นหมุด คลิกหมุดดูรายละเอียด คลิกบนแผนที่เพื่อวางหมุดใหม่ ลากหมุดปรับตำแหน่งได้
2. ฟอร์มข้อมูลต่อแปลง: ชื่อ, ประเภท (บ้าน/ที่ดิน), ราคา, พื้นที่ใช้สอย, จำนวนชั้น, จำนวนห้อง (นอน/น้ำ), ขนาดที่ดิน, ลิงก์ต้นทาง, หมายเหตุ, ชื่อคนเพิ่ม (พิมพ์เอง)
3. รายการข้างแผนที่ กรอง/เรียงตามราคาหรือขนาด คลิกรายการแล้วแผนที่เลื่อนไปที่หมุด
4. ข้อมูลอยู่ฐานข้อมูลกลางที่ทุกคนในกลุ่มเห็นตรงกัน เข้าด้วย "รหัสกลุ่ม"
5. ปุ่มส่งออก JSON (สำรองข้อมูล) และนำเข้า JSON
6. โฮสต์บน GitHub Pages แชร์เป็นลิงก์
7. โครงสร้างข้อมูลเผื่อช่องอนาคตไว้แล้ว (ไม่ต้องมี UI): ทรงหลังคา (roof), ทิศหน้าบ้าน (facing), กว้าง/ยาวตัวบ้าน (footprint)

## ขั้นถัดไป (ยังไม่ทำ เรียงตามที่แนะนำ — แต่ละขั้นคุยกันใหม่)
สถานที่สำคัญ (โรงพยาบาล ห้าง สนามบิน โรงเรียน ตลาด จาก OpenStreetMap + ระยะจากแต่ละบ้าน) → import ด้วย AI (ปุ่มคัดลอก prompt, วาง JSON กลับ, หาพิกัดจากที่อยู่) → โมเดล 3D เบื้องต้นจากขนาด/ชั้น/หลังคา/ทิศ วางบนแผนที่ → overlay เขตพื้นที่ (อุตสาหกรรม ที่อยู่อาศัย ฯลฯ; ข้อมูลผังเมืองหายาก ต้องหาแหล่งข้อมูลก่อน)

## Non-goals
ล็อกอินรายบุคคล, ระบบกันสแปม/ตรวจสอบข้อมูล, 3D ละเอียด, แอปมือถือเนทีฟ, ดึงข้อมูลจากเว็บประกาศอัตโนมัติ

## Anti-goals (ถือว่าล้มเหลวแม้ทำงานได้)
- ต้องติดตั้งโปรแกรมหรือรัน build ซับซ้อนเพื่อใช้/อัปเดต
- เพื่อนต้องสมัครบัญชีหรือกรอกอะไรยุ่งยากก่อนเพิ่มบ้านได้
- ข้อมูลหายหรือถูกเขียนทับเงียบๆ เมื่อสองคนแก้พร้อมกัน
- ต้องใช้บัตรเครดิตหรือมีค่าใช้จ่าย

## ข้อจำกัดและการตัดสินใจ
ตัดสินโดยผู้ใช้:
- ใช้งานในกลุ่มเพื่อน ข้อมูลต้องเชื่อมกัน (ทุกคนเห็นชุดเดียวกัน)
- เข้าด้วยรหัสกลุ่มร่วมกัน ไม่ล็อกอินรายบุคคล รู้ชื่อคนเพิ่มจากช่องพิมพ์ชื่อ
- โฮสต์บน GitHub Pages (repo public) ผู้ใช้มีบัญชี GitHub (thunder45456) แต่ยังไม่มี Supabase
- ความสำคัญ: แผนที่ + ข้อมูลบ้านก่อน

การตัดสินใจของผู้เขียน (ผู้ใช้ยังไม่ได้ยืนยันรายตัว):
- เทคโนโลยี: HTML/JavaScript ล้วน ไม่มีขั้นตอน build; แผนที่ Leaflet + พื้นหลัง OpenStreetMap (ฟรี ไม่ต้องมีคีย์)
- ฐานข้อมูล: Supabase แผนฟรี; ผู้ใช้ต้องสมัคร (ใช้บัญชี GitHub ได้) ผู้สร้างพาตั้งค่าทีละขั้น
- รหัสกลุ่ม: ไม่ใช่ความปลอดภัยจริงจัง ใครได้ลิงก์+รหัสก็แก้/ลบได้ เหมาะกับข้อมูลที่ไม่เป็นความลับ ห้ามใส่ข้อมูลส่วนตัว (เบอร์โทร เลขบัตร) ในช่องที่ออกแบบ
- ข้อมูลที่ฝังในหน้าเว็บ (URL/คีย์สาธารณะของ Supabase) จะมองเห็นได้ใน repo public — ใช้เฉพาะคีย์ anon; สิทธิ์เขียนควบคุมด้วย policy ฝั่งฐานข้อมูลที่ตรวจรหัสกลุ่ม
- ควรกันการลบพลาด (ยืนยันก่อนลบ; ปุ่มส่งออก JSON)
- UI ภาษาไทยเป็นหลัก ใช้ได้บนมือถือ (เพื่อนเปิดจากโทรศัพท์)

## ปล่อยให้ผู้สร้างตัดสิน
หน้าตา UI รายละเอียด, ชื่อฟิลด์/ตารางในฐานข้อมูล, วิธีตรวจรหัสกลุ่มฝั่ง Supabase, วิธีรับมือการแก้พร้อมกัน, หน่วยพื้นที่ (ตร.ม./ตร.วา/ไร่ — แนะนำให้เลือกหน่วยได้เพราะที่ดินไทยใช้ตร.วา/ไร่), วิธีหมุดแยกสีตามประเภท

## การตัดสินใจเพิ่มเติมของผู้เขียน (จากผลตรวจโดยผู้สร้างสมมติ — ผู้ใช้ตรวจได้)
- รหัสกลุ่ม: กลุ่มเดียวเท่านั้น (ไม่มีระบบสร้างกลุ่ม) ตั้งรหัสใน SQL ครั้งเดียว เก็บเป็น hash ในฐานข้อมูล ไม่ใส่ใน repo; ผู้ใช้พิมพ์รหัสตอนเข้า (จำในเบราว์เซอร์); ปิดการเข้าถึงตารางโดยตรง ใช้ RPC/RLS ตรวจ hash
- ข้อมูล: 1 แถวต่อ 1 แปลง มีคอลัมน์ version; บันทึกแล้วถ้า version ไม่ตรงให้เตือนความขัดแย้ง; ไม่ทำ realtime (รีเฟรชตอนเปิดและมีปุ่มรีโหลด)
- ลบ: soft delete (ถังขยะกู้คืนได้) + ยืนยันก่อนลบ
- นำเข้า JSON: เพิ่มเท่านั้น (additive) ถ้า id ซ้ำให้ข้ามและรายงาน มีขั้นยืนยัน
- Supabase แผนฟรีหยุดชั่วคราวเมื่อไม่ใช้ ~7 วัน: เพิ่ม GitHub Action ping รายวัน
- ฐานข้อมูลเข้าไม่ได้: แสดงข้อผิดพลาดชัดเจน อ่านอย่างเดียว ไม่ทำคิวออฟไลน์
- พื้นที่: เก็บค่ามาตรฐานเป็น ตร.ม. แสดง/กรอกได้ทั้ง ตร.ม./ตร.วา/ไร่
- ชื่อคนเพิ่ม: พิมพ์ครั้งเดียว จำในเบราว์เซอร์ บันทึกเฉพาะผู้เพิ่ม
- แผนที่: ไทล์ OpenStreetMap มาตรฐาน + attribution (กลุ่มเล็ก ใช้ได้)
