# HouseMap — บันทึกบ้านและที่ดินที่น่าสนใจบนแผนที่

เว็บสำหรับกลุ่มเพื่อนช่วยกันเก็บบ้าน/ที่ดินที่เจอ (เน้นเชียงใหม่และจังหวัดข้างเคียง) ทุกคนในกลุ่มเห็นข้อมูลชุดเดียวกัน

## วิธีใช้ (สำหรับเพื่อน)
1. เปิดลิงก์เว็บที่เจ้าของส่งให้ (ใช้ได้ทั้งคอมและมือถือ)
2. ใส่ **รหัสกลุ่ม** ที่เจ้าของส่งให้ทางส่วนตัว (ระบบจำรหัสไว้ในเบราว์เซอร์ของคุณ)
3. กด **+ เพิ่มรายการ** → กรอกข้อมูล → **คลิกบนแผนที่** เพื่อวางหมุด (ลากปรับได้) → บันทึก
4. คลิกหมุดหรือรายการเพื่อดูรายละเอียด และกด "แก้ไข" ได้
5. ถ้าสองคนแก้รายการเดียวกันพร้อมกัน ระบบจะเตือนและไม่ทับข้อมูลของอีกคน
6. ลบแล้วกู้คืนได้จากปุ่ม **ถังขยะ**

พื้นที่กรอกได้เป็น ตร.ม. / ตร.วา / ไร่ (1 ตร.วา = 4 ตร.ม., 1 ไร่ = 1,600 ตร.ม.) ราคาเป็นบาท

## สถานที่สำคัญ
- ติ๊ก "แสดงบนแผนที่" เพื่อดูโรงพยาบาล ห้าง สนามบิน โรงเรียน ตลาด (ปิดไว้เป็นค่าเริ่มต้น)
- ทุกบ้านแสดงสถานที่ที่ใกล้ที่สุดของแต่ละประเภท เป็นระยะเส้นตรง (ไม่ใช่ระยะตามถนน)
- กรองบ้านได้ เช่น "ใกล้โรงพยาบาล ไม่เกิน 5 กม."
- ข้อมูลมาจาก OpenStreetMap (© OpenStreetMap contributors, ODbL) เป็นไฟล์ `landmarks.json` ดึงใหม่ด้วย `python tools/fetch_landmarks.py` ข้อมูลมาจากอาสาสมัคร อาจมีบางจุดผิดหรือขาด

## เส้นทาง
- คลิกรายการด้านขวาเพื่อขยายดูรายละเอียด แล้วกด **แสดงเส้นทาง** ไปยังสถานที่ที่ใกล้ที่สุดของแต่ละประเภท (หรือ **แสดงทุกเส้นทาง**) เส้นแต่ละประเภทใช้สีเดียวกับจุดบนแผนที่ พร้อมระยะตามถนนและเวลาขับรถโดยประมาณ
- เส้นทางคำนวณจาก OSRM demo server (ฟรี ใช้เบาๆ ได้) สถานที่ "ใกล้สุด" เลือกจากระยะเส้นตรง ซึ่งบางครั้งไม่ใช่ที่ใกล้สุดตามถนน

## นำเข้าด้วย AI
1. กด **นำเข้าด้วย AI** → **คัดลอก prompt**
2. นำไปวางในแชท AI (เช่น Claude) พร้อมข้อความหรือรูปจากหน้าประกาศ
3. วางคำตอบของ AI กลับในช่อง แล้วกด **อ่านคำตอบ** เว็บจะเปิดฟอร์มที่กรอกให้ ถ้ามีแต่ที่อยู่ เว็บจะค้นหาพิกัดให้โดยประมาณ (จาก Nominatim ของ OpenStreetMap) ลากหมุดปรับได้ ถ้ามีหลายรายการจะไล่ทีละรายการ
- AI อาจอ่านผิด ตรวจทุกช่องก่อนบันทึก และ prompt สั่งไม่ให้ใส่เบอร์โทรหรือข้อมูลส่วนตัว

## สำรองข้อมูล
- **ส่งออก JSON** ดาวน์โหลดไฟล์สำรองทั้งหมด (รวมถังขยะ)
- **นำเข้า JSON** เพิ่มเฉพาะรายการที่ยังไม่มี ข้ามรายการซ้ำ และถามยืนยันก่อน

## ข้อควรรู้
- รหัสกลุ่ม **ไม่ใช่ความปลอดภัยระดับจริงจัง** ใครมีลิงก์และรหัสก็แก้หรือลบข้อมูลได้
- **อย่าใส่ข้อมูลส่วนตัว** (เบอร์โทร เลขบัตร ที่อยู่เจ้าของบ้านที่ระบุตัวตนได้) ในช่องใดเลย
- ถ้าฐานข้อมูลเชื่อมต่อไม่ได้ เว็บจะดูได้อย่างเดียวและแจ้งเตือนด้านบน

## สำหรับเจ้าของ (ตั้งค่าครั้งเดียว)
- ฐานข้อมูล: Supabase แผนฟรี รัน `supabase/schema.sql` แล้ว `supabase/set_group_code.sql` (แก้ `REPLACE_ME` เป็นรหัสกลุ่มอย่างน้อย 8 ตัว **และไม่บันทึกกลับลงไฟล์**)
- ถ้าตั้งไว้ก่อนมี `migrate_2_bcrypt.sql`: รันไฟล์นั้นหนึ่งครั้ง แล้วรัน `set_group_code.sql` ต่อทันที (ไม่งั้นเว็บจะปฏิเสธทุกรหัส)
- ใส่ Project URL และ anon key ใน `js/config.js` (สองค่านี้เป็นค่าสาธารณะ ห้ามใส่ `service_role`)
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root
- GitHub Actions secrets `SUPABASE_URL`, `SUPABASE_ANON_KEY` สำหรับ `keepalive.yml` (ping ทุกวัน กัน Supabase หยุดเมื่อไม่มีคนใช้)
- เปลี่ยนรหัสกลุ่ม: รัน `set_group_code.sql` ใหม่ แล้วแจ้งเพื่อน
