# HouseMap — บันทึกบ้านและที่ดินที่น่าสนใจบนแผนที่

เว็บสำหรับกลุ่มเพื่อนช่วยกันเก็บบ้าน/ที่ดินที่เจอ (เน้นเชียงใหม่และจังหวัดข้างเคียง) ทุกคนในกลุ่มเห็นข้อมูลชุดเดียวกัน

## วิธีใช้ (สำหรับเพื่อน)
1. เปิดลิงก์เว็บที่เจ้าของส่งให้ (ใช้ได้ทั้งคอมและมือถือ)
2. ใส่ **รหัสกลุ่ม** ที่เจ้าของส่งให้ทางส่วนตัว (ระบบจำรหัสไว้ในเบราว์เซอร์ของคุณ)
3. กด **+ เพิ่มรายการ** → กรอกข้อมูล → **คลิกบนแผนที่** เพื่อวางหมุด (ลากปรับได้) → บันทึก
4. คลิกหมุดหรือรายการเพื่อดูรายละเอียด และกด "แก้ไข" ได้
5. ถ้าสองคนแก้รายการเดียวกันพร้อมกัน ระบบจะเตือนและไม่ทับข้อมูลของอีกคน
6. ลบแล้วกู้คืนได้จากปุ่ม **ถังขยะ**

พื้นที่กรอกได้เป็น ตร.ม. / ตร.วา / ไร่ (1 ตร.วา = 4 ตร.ม., 1 ไร่ = 1,600 ตร.ม.) ราคาเป็นบาท

## สำรองข้อมูล
- **ส่งออก JSON** ดาวน์โหลดไฟล์สำรองทั้งหมด (รวมถังขยะ)
- **นำเข้า JSON** เพิ่มเฉพาะรายการที่ยังไม่มี ข้ามรายการซ้ำ และถามยืนยันก่อน

## ข้อควรรู้
- รหัสกลุ่ม **ไม่ใช่ความปลอดภัยระดับจริงจัง** ใครมีลิงก์และรหัสก็แก้หรือลบข้อมูลได้
- **อย่าใส่ข้อมูลส่วนตัว** (เบอร์โทร เลขบัตร ที่อยู่เจ้าของบ้านที่ระบุตัวตนได้) ในช่องใดเลย
- ถ้าฐานข้อมูลเชื่อมต่อไม่ได้ เว็บจะดูได้อย่างเดียวและแจ้งเตือนด้านบน

## สำหรับเจ้าของ (ตั้งค่าครั้งเดียว)
- ฐานข้อมูล: Supabase แผนฟรี รัน `supabase/schema.sql` แล้ว `supabase/set_group_code.sql` (แก้ `REPLACE_ME` เป็นรหัสกลุ่ม **และไม่บันทึกกลับลงไฟล์**)
- ใส่ Project URL และ anon key ใน `js/config.js` (สองค่านี้เป็นค่าสาธารณะ ห้ามใส่ `service_role`)
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / root
- GitHub Actions secrets `SUPABASE_URL`, `SUPABASE_ANON_KEY` สำหรับ `keepalive.yml` (ping ทุกวัน กัน Supabase หยุดเมื่อไม่มีคนใช้)
- เปลี่ยนรหัสกลุ่ม: รัน `set_group_code.sql` ใหม่ แล้วแจ้งเพื่อน

## ทดสอบ
- `node --test "tests/*.test.mjs"` — ทดสอบตรรกะ (ไม่ต้องใช้เน็ต)
- `GROUP_CODE=... node tests/api_smoke.mjs` — ทดสอบกับ Supabase จริง
- `tests/e2e_*.js` — สคริปต์ทดสอบในเบราว์เซอร์ผ่าน Edge (แทน `__CODE__` ด้วยรหัสตอนรัน)
